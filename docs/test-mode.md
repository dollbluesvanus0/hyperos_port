# Тестовая сборка без патчей APK/JAR

В GitHub Actions откройте **Build HyperOS port → Run workflow** и включите
**test_mode**. Остальные параметры сборки выбираются как обычно.

Для локальной сборки установите `test_mode=true` в `bin/port_config`, затем
запустите `sudo bash port.sh <сток.zip> <донор.zip>`. По умолчанию режим выключен.

В тестовом режиме отключены:

- Все патчи smali, ресурсов и методов через apktool/APKEditor, включая
  `services.jar`, `miui-services.jar`, SystemUI, Settings, PowerKeeper и темы.
- Подмена APK оверлеев, MiSound, MiuiBiometric и Hotword из стоковой прошивки.
- Скачивание и установка новой MiuiCamera; остаётся камера донора.
- Удаление приложений, включая старую очистку `product/data-app` и оба списка
  debloat, а также подмена APK/JAR из NFC-пакетов.
- APK/JAR в `devices/<устройство>/overlay`; остальные файлы этого оверлея
  продолжают копироваться.

Слияние `mi_ext`, правки `build.prop`, настройки XML, fstab, AVB, ядра и упаковка
разделов продолжают работать. Режим отключает изменения APK/JAR и позволяет
проверить их влияние на загрузку; совместимость стока и донора проверяется отдельно.

После слияния `mi_ext` скрипт записывает пути и SHA256 APK/JAR всех разделов в
`build/archive-test-baseline.json`. Перед упаковкой он проверяет, что файлы не
изменились, не исчезли и не добавились. При любой разнице сборка останавливается.
Ссылки APK/JAR проверяются по цели ссылки без обращения к абсолютным путям Android.
В Actions манифест сохраняется вместе с логом сборки.

Оба формата выходного ZIP получают суффикс `_TEST`. Для возвращения обычных патчей
отключите **test_mode** в Actions или установите `test_mode=false` в конфиге.
